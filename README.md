# NEXUS OFFICE

A procedural, low-poly office walkthrough built with Vite, React, TypeScript, and React Three Fiber. The scene uses generated geometry only; no external 3D assets are required.

## Live site

The site is deployed to [GitHub Pages](https://thehamna73-oss.github.io/nexus-office/) whenever a commit is pushed to `main`.

## Run locally

```sh
npm install
npm run dev
```

For a production build, run `npm run build`.

Click an open patch of floor or use WASD / arrow keys to explore after arriving at reception. Choose a room to follow the receptionist on a guided visit. Use the sound pill to enable the generated ambience and footsteps after a user gesture. Edit the visitor-facing labels and room descriptions in `src/config.ts`.
